## Research page

The former Research and Projects pages are now combined.

The Research page has two clearly distinct sections:

1. **Research Areas — What we study**
   - In-Situ Sensing
   - Digital Twin & Simulation
   - Physics–AI
   - Structural Validation
   - Adaptive Control & Decision-Making

2. **Selected Projects — Where we apply it**
   - Continuous Fiber Printing
   - Tire Health Monitoring
   - Event Camera / Melt Pool Monitoring
   - WAAM

This avoids duplicating the same content in two top-level pages.

## Replacing figures

All visual placeholders remain in `assets/img/`.
Replace a placeholder image with your own figure using the same filename.

## GitHub Pages

Upload everything to a GitHub repository and enable:
Settings → Pages → Deploy from a branch → main → / (root)

`projects.html` is retained only as a redirect to `research.html#projects`, so old links will still work.
